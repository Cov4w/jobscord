# JobsCord Project (가제)

> **학습을 주 목표로 시작하여, 최종적으로는 포트폴리오 및 통합 웹 페이지로 발전시켜 나가는 팀 프로젝트입니다.**

---

## 🎯 프로젝트 목표

1. **기술 학습 및 실전 적용**
   * 기존에 학습한 기술(ASP.NET Core, WPF MVVM, MySQL, REST API)을 실제 프로젝트에 통합 적용합니다.
   * 실시간 양방향 통신을 위해 **SignalR**을 새롭게 학습하고 구현합니다.
2. **단계적 확장 (최종 목표)**
   * 핵심 채팅 기능 구현을 시작으로, 향후 팀원들의 **개인 포트폴리오 및 통합 웹 페이지**로 확장해 나갈 예정입니다.

---

## 🛠️ 기술 스택

| 구분 | 기술 | 역할 |
| :--- | :--- | :--- |
| **Server** | ASP.NET Core, REST API | 사용자 인증, 서버/채널 로직, API 요청 처리 |
| **Real-time** | SignalR | 실시간 텍스트 채팅, 접속 상태, 알림 전달 |
| **Client** | WPF (MVVM) | 데스크톱 클라이언트 UI (로그인, 채널, 채팅방 등) |
| **Database** | MySQL | 회원, 서버, 채널, 메시지, 친구 관계 데이터 저장 |

---

## 📌 주요 개발 예정 기능 (Roadmap)

*초기 기획 단계로, 학습 및 개발 진행 상황에 따라 유연하게 변경될 수 있습니다.*

- [ ] **실시간 통신 (SignalR):** 실시간 텍스트 채팅, 온라인 상태 표시
- [ ] **기본 기능 (REST API):** 로그인/회원가입, 서버 및 채널 생성·조회, 메시지 기록 조회
- [ ] **확장 기능:** 음성 채팅 및 STT 기반 음성 대화 텍스트 요약
- [ ] **문서화:** API 명세서 작성 및 GitHub 연동
- [ ] **최종 확장:** 팀원별 포트폴리오 및 프로젝트 통합 웹 페이지 구축
